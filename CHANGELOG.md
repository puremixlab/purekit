# Changelog

## Unreleased

- Rebranded the kit and its documentation as PureKit. Import components from the `github.com/puremixlab/purekit` Go module.
- Added data tables, outlines, collection and column browsers, split views, inspectors and shared toolbar commands.
- Added desktop input controls, date ranges, path and image wells, rich text editing, charts, level indicators and a filter rule editor.
- Added native desktop sheets, panels, file save dialogs and status items, with macOS sharing, fonts and Quick Look.

- Button with six variants and three sizes.
- Lobe UI tokens generated into Go.
- `theme.Config` applies an app's own light and dark tokens, and `PrimaryForeground` sets the label color on solid primary surfaces.
- `AlertProps.Selectable` lets people select and copy an alert's text.
- `HotkeyProps.Size` supports compact `theme.Small` key caps, used by small `SearchBar` inputs.
- Web catalog of live MyGo demos.
