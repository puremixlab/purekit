Use `display.Table` with a `ui.ListState` and a cell builder. Give the table a bounded height to scroll. Set `Key` on the state to keep a row's selection when the data is reordered.

Click a column heading to change its sort order. Drag a heading edge to resize it. Use Command or Ctrl to toggle rows, Shift to extend the selection, and the arrow keys to move it.
