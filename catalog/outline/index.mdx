Call `display.Outline` with unique item keys and a function that returns the children of each branch. Keep `ui.OutlineState` with the view to preserve opened branches and selection.

Select a row to focus the tree. Use the Right and Left arrow keys to expand and collapse a branch or move through its hierarchy.
