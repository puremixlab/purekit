Choose a folder, select a document to show its details, and press Enter to preview it. Drag either divider or focus it with Tab and use the arrow keys to resize the panes. Double-click a divider to restore its default size.

<GoDemo name="workspace/basic" title="Document workspace" height={360} source={source} />

## Native example

Run `go run ./examples/workspace` for a desktop window with a Workspace menu and saved pane sizes. The menu and toolbar use the same `command.Command` values. The View uses `HandleShortcuts` when hosted without native menu accelerators.
